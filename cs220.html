CS 220 Project Process

Problem Statement

Many Wellesley students, especially those with busy schedules, struggle to access affordable and high-quality beauty services such as nail polishing, lash extensions, and haircuts. While some students travel off-campus to find cheaper options, this process is time-consuming and inconvenient. For students balancing classes, extracurriculars, and part-time jobs, it is difficult to manage both time and cost when seeking these services. This issue particularly affects college students who want to maintain self-care or a professional appearance but lack accessible, campus-based solutions.

Low Fid Prototype

We created a black and white prototype of the application using the feedback and criticism that we got from the first feedback loop. In this prototype, we included these important pages: Home page, where users can find reviews and promotions and foster a community; Search page, where users can look up services based on their location; Profile page, where users can update their personal information and see their booking information; Chat page, where users can chat with their artists or their clients.

P4 Feedback

  • Booking flow: Users attempted to book from the homepage instead of the intended booking section
  • Information availability: Users expected to see the average response time and frequent active hours displayed on profiles, but these were not presented
  • Tab bar visibility: Users had difficulty finding the chat function and overlooking the bottom tab bar
  • Chat function: Users expected to have chat boxes directly under posts or booked services, as well as an indication of average reply time, but these were not presented
  • Token system: The “Available Tokens” feature was confusing as users didn’t understand what tokens were, how to use or spend them, or how tokens were subtracted after booking

High Fid Prototype

After getting the feedback from our participants, in our high-fidelity Figma prototype, we decided that on top of adding colors and making the application more detailed, we added some other functions: Separated tab bars, so that the clients can have their search and the artist can have their shop; Shop item page, so that the artists can look into the shop item and see item descriptions; Canceling booking in profile, so that users are able to cancel bookings. And adding these additions and colors concluded our P5 high-fidelity prototype.

P6 Testing

  • Button Sizes: Back buttons are too small, making them hard to tap for some users. Fitts’ Law should be applied in terms of target size and accessibility.
  • Profile Icon: The profile icon does not link to a full profile page, and only the profile name is linked. Both sections should be linked to support convenient switching between roles.
  • Shop Promotions: The homepage lacks promotion for the toolkit shop in the homepage promotion section. It would benefit artists if this promotion were shown when launching the app, so they know how to spend their tokens.
  • Booking flow: After a user enters the booking confirmation page and chooses to chat with an artist, there is no clear path back to the booking confirmation flow.

Future Works

  • Back buttons are too small, making them hard to tap for some users. Fitts’ Law should be applied in terms of target size and accessibility.
  • The profile icon does not link to a full profile page, and only the profile name is linked. Both sections should be linked to support convenient switching between roles.
  • The homepage lacks promotion for the toolkit shop in the homepage promotion section. It would benefit artists if this promotion were shown when launching the app, so they know how to spend their tokens.
  • After a user enters the booking confirmation page and chooses to chat with an artist, there is no clear path back to the booking confirmation flow. The system redirects to the chat homepage instead of continuing the booking process. A suggested fix from a user is to provide a “Continue Booking” pop-up, which would reduce drop-offs and prevent users from forgetting to complete their reservation.
